### 首帧底栏骨架（解决「打开首页看不到底栏、滑到底才出现」）
- **根因**：`main.tsx` 的 `boot()` 是 async——先 `await hydrateSiteData()`（11 个并发 `/api` 请求、各 timeout 3500ms），才 `createRoot().render()`。底栏是 CSR `createPortal` 到 body，JS 挂载前 DOM 里根本没有它（`navCount:0`，实测约 500ms 后才出现），弱网被放大成「打开首页看不到底栏」。
- **方案**：`index.html` 在 `#root` **之外**加静态底栏 `<nav id="boot-tabbar" aria-label="底部导航">`，5 项与 React 版一致（首页/AI知识库/生活/我的/AI分身），全内联样式（含 `position:fixed`、`rgb(var(--c-ink,...) / .45)` 带 fallback）首帧即显示、`<a href>` 可点。**放在 root 外是关键**：`prerender.mjs` 用 `/<div id="root">\s*<\/div>/` 匹配空 root 注入正文，往 root 里加内容会让预渲染失效。
- `index.html` head 内加 `<style id="boot-tabbar-style">`：`#boot-tabbar{display:block!important}` + `@media(min-width:1024px){display:none!important}`。必须内联（不放 index.css），因为 dev 下 CSS 靠 JS 注入、JS 未就绪时外部 CSS 也缺位。
- `Layout.tsx` MobileTabBar 加 `useEffect(() => { document.getElementById('boot-tabbar')?.remove() }, [])`，真底栏 commit 后移除骨架，无空窗。
- **验证**：dev 拦截 main.tsx → 骨架 fixed 贴底 5 项；桌面视口骨架 display:none；生产 dist 起 `vite preview` 拦截全部 *.js（JS 未就绪+预渲染正文在）→ 骨架首帧在、下滑 scrollY=845 后仍 fixed 贴底(bottom=844=视口高)；生产正常加载 → 骨架移除、只剩真底栏、技能图谱可见、下滑 2500 停留 scrollY 稳定、底栏 fixed 贴底。
