## 📌 一、产品概述

### 1.1 项目简介

| 项目 | 内容 |
| --- | --- |
| 产品名称 | **WYX.SPACE**（个人作品站 / 数字名片） |
| 产品定位 | 「一个人 = 一个网站 + 一个 AI 助理」的个人品牌基础设施：作品展示、内容沉淀、简历投递、访客互动与数据洞察一体化 |
| 一句话价值 | 把散落在 GitHub / 博客 / 网盘 / 简历 PDF 里的个人信息，收拢成一个可搜索、可对话、可持续运营的站点 |
| 当前形态 | React 18 + TypeScript + Vite 前端；零依赖 Node API（`npm run api`）；AI 站内助手（RAG 检索 + 引用） |
| 目标形态 | 前后端分离 + 移动端适配；后端迁移至 **Python 3.11 + FastAPI**，数据库 PostgreSQL，AI 网关独立 |

### 1.2 用户与使用场景

| 用户角色 | 典型画像 | 核心诉求 | 使用场景 |
| --- | --- | --- | --- |
| 站主（Owner） | 求职中的开发者 / 研究者 / 设计师 | 低成本维护个人品牌，内容随时更新 | 发布文章与项目、维护简历、审核留言、看访问数据 |
| 管理员（Admin） | 站主本人或协作者 | 内容治理、权限隔离、数据安全 | 后台 23 个 Tab、审计日志、备份恢复 |
| 编辑（Editor） | 朋友 / 实习生 | 只改内容，不碰系统配置 | 文章与动态编辑、留言审核 |
| 访客（Visitor） | 招聘方、同行、朋友 | 30 秒看懂「你是谁、做过什么」 | 首页浏览、读文章、看简历、下载文件、AI 提问 |
| 互动用户（Guest） | 留言 / 索要资料的访客 | 低门槛留下联系与反馈 | 留言板、友链申请、文件分享短链 |

### 1.3 痛点与价值

| 现状痛点 | 具体表现 | 本产品的解法 | 可量化价值 |
| --- | --- | --- | --- |
| 信息碎片化 | 简历在 PDF、项目在 GitHub、生活动态在朋友圈 | 一个站点统一承载「工作 / 生活 / 关于」三层内容 | 招聘方了解成本从 3 份材料降到 1 个链接 |
| 静态作品集「只读」 | 访客找不到想看的细节，只能自己翻 | AI 助手基于站内内容回答，并给出原文引用 | 追问轮次下降，关键信息触达率提升 |
| 建站门槛高 | WordPress 重、纯静态站不能写不能审 | 开箱即用的内容管理 + 审核 + 文件 + 埋点 | 从「会写代码」降到「会填表」 |
| 数据不真实 | 演示数据冒充真实流量，决策失真 | 真实埋点 + 数据口径门禁（`check:data`） | 看板数字可追溯到 `/api/analytics/summary` |
| 运维不可控 | 无审计、无备份、无回滚 | 审计日志、全量快照、版本回滚、乐观锁 | 误操作可恢复，变更可追责 |
| 移动端体验差 | 后台表格在手机上不可用 | 响应式断点 + 抽屉式侧栏 + 触控目标 ≥ 44px | 手机可完成审核与发布 |

### 1.4 竞品调研

| 竞品 | 形态 | 优势 | 短板 | 我们的差异化 |
| --- | --- | --- | --- | --- |
| GitHub Pages / Vercel 静态站 | 静态托管 | 免费、快、部署简单 | 无后台、无互动、无数据 | 自带后台与 AI，内容可运营 |
| Notion / FlowUs 公开页 | 文档站 | 编辑体验好 | 品牌感弱、无代码级定制、AI 不通站内内容 | 完全品牌化 + 站内 RAG |
| WordPress | CMS | 插件生态大 | 重、需运维、安全面大 | 零依赖起步、攻击面小 |
| Framer / Webflow | 可视化建站 | 设计自由度高 | 订阅贵、数据在平台 | 数据自有、可导出、可自托管 |
| 超级简历 / 简历鸭 | 简历工具 | 模板多、导出快 | 只有简历，无作品与内容 | 简历是子模块，作品与内容可联动 |
| 个人博客模板（Hexo/Hugo） | 静态博客 | 轻、主题多 | 无审核、无文件、无 AI | 内容 + 互动 + AI + 数据一体 |

**结论**：竞品要么「只有展示」，要么「只有工具」。WYX.SPACE 的差异化是 **展示 + 运营 + AI 问答 + 数据洞察** 四合一，且可自托管、数据自有。

| 功能 | 验收标准 |

## 🤖 四、AI 具体应用与价值

| # | 应用场景 | 输入 | 输出 | 实现要点 | 用户价值 | 衡量指标 |
| --- | --- | --- | --- | --- | --- | --- |
| A-01 | 站内问答助手 | 问题 + 页面上下文（文章 ID / 简历段） | 流式回答 + 3 条引用 | 先检索后生成；无密钥走检索回答 | 访客不用翻页就能问「他做过什么 RAG 项目」 | HitRate@5、引用正确率 |
| A-02 | 内容检索索引 | 文章/项目/简历文本 | 可检索片段与来源 | 索引失效时自动重建 | 回答始终基于最新内容 | 索引新鲜度 |
| A-03 | 答案缓存 | 归一化问题 + 上下文 + Prompt 版本 | 缓存命中结果 | `sha256(问题|上下文|版本)`，6 小时 | 降本、降延迟 | 缓存命中率 |
| A-04 | 安全与注入防护 | 用户输入 | 拦截或安全回答 | 注入样例规则 + 输出边界 | 避免提示词被套取 | 注入拦截率 100% |
| A-05 | 配额与成本控制 | IP、tokens、模型 | 429 / 预算告警 / 用量报表 | 按天配额 + 月 token 预算 | 成本可预期 | 日配额使用率、单次成本 |
| A-06 | Prompt 运营 | Prompt 内容 | 版本、A/B 效果 | 版本化 + 回滚 | 不写代码也能调回答质量 | 版本采纳率 |
| A-07 | 评测闭环 | 40 条问答 + 8 条注入 | 命中率/MRR/引用正确率报告 | `scripts/eval-ai.mjs` | 改动可回归验证 | HitRate@5 ≥ 0.85、MRR ≥ 0.65 |
| A-08 | 简历解析 | 简历文本 | 结构化字段 + 置信度 | 规则抽取（模型可选） | 3 秒生成简历草稿 | 字段识别率 |
| A-09 | 运营周报 | 看板数据 | 规则周报（非模型） | 模板化摘要 | 站主每周 1 分钟看结论 | 生成耗时 |
| A-10 | AI 配置后台 | 模型、密钥、开关 | 生效配置 | 密钥仅服务端，前端只显示状态 | 可换模型不换代码 | 配置变更成功率 |

**AI 的价值主张**：不是「炫技聊天框」，而是把站内内容变成**可对话的知识资产**——访客问得到、站主管得住、成本算得清、效果测得准。

## 🏗️ 五、技术架构

> 硬性要求：**前后端分离**、**适配移动端网页**；前端 React/Vue/TypeScript，后端 Java/Python/FastAPI。
> 本项目前端已为 React + TypeScript；后端现状为 Node 零依赖 API，PRD 目标架构为 **Python 3.11 + FastAPI**（接口契约已通过 `/api/openapi.json` 收敛，可平滑替换）。

### 5.1 分层架构

| 层级 | 现状（仓库） | PRD 目标 | 说明 |
| --- | --- | --- | --- |
| 展示层 | React 18 + TypeScript + Vite 5 + Tailwind + framer-motion + lucide-react | 保持 React + TS（可选 Vue 3 作为二次开发分支） | 路由级懒加载 + 预渲染保首屏 |
| 移动端适配 | Tailwind 响应式断点 + 抽屉侧栏 + 触控目标 ≥ 44px | 移动优先断点（`sm/md/lg`）、SSR/预渲染、PWA 离线 | 后台表格在手机上转为卡片流 |
| 网关/API 层 | 零依赖 Node HTTP（`server/index.mjs`，端口 8787） | **Python 3.11 + FastAPI**（Pydantic 校验、OpenAPI 自动文档） | 路由按域拆分：auth / content / files / analytics / ai / system |
| 业务层 | `server/routes/*`、`server/lib/*` | FastAPI `routers/*` + `services/*` | 保留现有错误体 `{code,message,requestId}` |
| 数据层 | JSON 文件 + 原子写（`JsonStore`） | PostgreSQL 16 + SQLAlchemy 2.x / Alembic 迁移 | 账户三表先行，见 [数据库.md](computer://e:\Code\AI\Start\Web\Blog\resume1\数据库.md) |
| 缓存层 | 进程内 Map（限流、聚合缓存、AI 缓存） | Redis（多实例时） | 单实例阶段可继续用内存实现 |
| AI 层 | RAG 检索 + OpenAI 兼容网关 + 用量记账 | 独立 AI 服务 + 向量库（`pgvector`） | 密钥仅服务端，前端只见状态 |
| 文件存储 | 本机 `server/data/uploads` + 签名直传 | S3 / OSS 兼容驱动（`STORAGE_DRIVER`） | 接口与签名同构，换驱动不改前端 |
| 部署 | Docker + `docker-compose.yml`（api 服务） | Nginx 反代 + FastAPI（uvicorn/gunicorn）+ Postgres + 静态资源 CDN | HTTPS 下 Cookie 自动 `Secure` |

### 5.2 核心接口（契约稳定）

| 能力 | 接口 | 方法 | 鉴权 | 说明 |
| --- | --- | --- | --- | --- |
| 登录 | `/api/auth/login` | POST | 公开 + 限流 | HttpOnly Cookie 会话 |
| 会话 | `/api/auth/session` | GET | 会话 | 返回 user/role/expiresAt |
| 内容读 | `/api/content/{domain}` | GET | 公开（只返回 published） | cursor 分页 + ETag/304 |
| 内容写 | `/api/content/{domain}/{id}` | PUT | admin/editor | `If-Match` 乐观锁，冲突 409 |
| 留言 | `/api/guestbook` | GET/POST | 公开 / 限流 | 提交进 pending，公开墙只出 published |
| 文件 | `/api/files/sign`、`/api/files/share` | POST | admin/editor | 签名直传、短链分享 |
| 埋点 | `/api/track` | POST | 公开 + 限流 | 只存 IP 哈希 |
| AI | `/api/ai/chat` | POST | 公开 + 配额 | SSE：delta / done / error |
| 总览 | `/api/admin/overview` | GET | admin | KPI + 7/30 天趋势 |
| 备份 | `/api/admin/backup` | GET/POST | admin | 快照列表 / 创建 |

### 5.3 非功能指标

| 类别 | 指标 | 目标 |
| --- | --- | --- |
| 性能 | 首屏 TTFB / 入口包体积 | 预渲染保证首屏有正文；入口 gzip ≤ 50 kB |
| 可用性 | `/healthz`、`/readyz` | 健康检查 + 数据目录可写探针 |
| 安全 | 口令、会话、CSRF、CSP | scrypt 哈希；`HttpOnly + SameSite=Lax`；Origin 校验；CSP 白名单 |
| 可维护性 | 质量门禁 | `check:data` / `check:contrast` / `check:budget` / `check:api` / `eval:ai` |
| 可移植性 | 数据出口 | JSON 全量导出 + PostgreSQL 备份；无平台锁定 |

## 🧭 六、用户操作流程

| # | 角色 | 场景 | 操作步骤 | 系统输出 | 异常与兜底 |
| --- | --- | --- | --- | --- | --- |
| F-01 | 访客 | 首次访问 | 打开首页 → 看首屏名片 → 点精选项目 → 进阅读页 | 预渲染正文、项目详情、相关文章 | 断网显示离线页；可重试 |
| F-02 | 访客 | 想快速了解 | 打开 AI 助手 → 提问「做过哪些 RAG 项目」→ 看引用 | 流式回答 + 3 条引用 + 追问建议 | 无模型密钥时走检索回答；超配额 429 |
| F-03 | 访客 | 留联系方式 | 填写昵称/邮箱/内容 → 提交留言 | 进入待审队列，返回 201 | 频率过高 429；重复提交去重 |
| F-04 | 访客 | 下载资料 | 文件页 → 选文件 → 下载 / 输入分享密码 | 文件流（支持 Range） | 链接过期 404；密码错误 401 |
| F-05 | 管理员 | 登录后台 | `/admin` → 输入账号密码 → 进入首页总览 | 会话 Cookie + KPI 看板 | 密码错误 401；连续失败限流 |
| F-06 | 管理员 | 日常巡检 | 首页总览 → 看 7 天趋势 → 点「待审」徽标 | 趋势图、待办数量 | 数据为空显示空状态，不伪造 |
| F-07 | 管理员 | 发布文章 | 内容管理 → 新建 → 保存草稿 → 提交审核 → 发布 | 新版本号、状态变更、审计记录 | 并发编辑 409；非法状态迁移 422 |
| F-08 | 管理员 | 审核互动 | 审核 → 留言/友链 → 通过或拒绝 | 状态变更、公开墙刷新、badge 更新 | 重复审核幂等 |
| F-09 | 管理员 | 维护简历 | 简历管理 → 粘贴文本解析 → 调整模块 → 创建版本 | 结构化字段、版本快照 | 解析失败进死信队列可重试 |
| F-10 | 管理员 | 上传与分享 | 文件资源 → 申请签名 → 上传 → 生成分享短链 | 文件记录、短链 URL | 未签名上传被拒；体积超限 413 |
| F-11 | 管理员 | 调整 AI | AI 配置 → 改 Prompt → 看用量 → 回滚版本 | 新版本生效、成本报表 | 密钥缺失时明确标注 retrieval-only |
| F-12 | 管理员 | 改密与安全 | 个人中心 → 安全 → 输入当前密码 + 新密码 | 改密成功、旧会话失效 | 当前密码错误 401 |
| F-13 | 管理员 | 备份恢复 | 站点设置 → 备份 → 创建快照 / 恢复 | 快照文件、恢复结果 | 快照格式错误 422；恢复后索引重建 |
| F-14 | 管理员 | 移动端应急 | 手机打开 `/admin` → 抽屉侧栏 → 审核一条留言 | 与桌面一致的操作结果 | 小屏表格转卡片流 |
